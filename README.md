# Real-Time Chat Application

A real-time chat application built with Node.js, Express, Socket.IO, and MongoDB. Features JWT authentication, Google Sign-In, and live messaging capabilities.

## Features
- 🔐 User authentication (Email/Password & Google Sign-In)
- 💬 Real-time messaging with Socket.IO
- 👥 Active users list
- 🔒 JWT token-based authorization
- 📱 Responsive Bootstrap UI

## Installation
npm install


## Environment variables
use .env.example

## Run
npm run dev

The server will start on http://localhost:8080
